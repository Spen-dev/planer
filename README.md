# Планер

Недельный планер и матрица Эйзенхауэра на основе Excel-шаблона `Планер.xlsx`.

## Запуск

В корне репозитория лежит **`Planer.exe`** — один файл, дополнительная установка не нужна.

1. Скачайте или клонируйте репозиторий.
2. Запустите `Planer.exe`.

Данные сохраняются локально на компьютере в **зашифрованном виде** (пароль задаётся при первом запуске).

## Защита

- **Лицензионный ключ** — обязателен при запуске `Planer.exe`
- **Шифрование данных** — AES-GCM + PBKDF2, пароль пользователя
- **Шифрованные бэкапы** — кнопка «Сохранить» создаёт `.planer` файл
- **Обфускация JS** — код минифицируется при сборке exe
- **EULA** — см. файл `LICENSE`

### Активация

1. Запустите `Planer.exe`
2. Введите лицензионный ключ формата `PLAN-XXXX-XXXX-XXXX-XXXX`
3. Задайте пароль шифрования (не короче 6 символов)

### Генерация ключей (для автора)

```bat
cd src
python generate_key.py customer-001
```

Перед выпуском измените секрет в `src/license.py` (`LICENSE_SECRET`).

## Возможности

### Недельный планер
- 7 дней недели (Пн–Вс) в одной строке
- Переключение недель и кнопка «Сегодня»
- До 15 задач на день с чекбоксами
- Прогресс, завершённые и невыполненные задачи
- 4 заметки на день
- Кнопка **«Сохранить»** — экспорт зашифрованного бэкапа (`.planer`)

### Матрица Эйзенхауэра
- Срочно и важно
- Срочно, но не важно
- Важно, но не срочно
- Не важно и не срочно

## Структура проекта

```
planer/
  Planer.exe    — готовое приложение
  src/          — исходники и сборка
```

## Сборка exe

```bat
cd src
build.bat
```

Нужны Python 3, WebView2 Runtime и зависимости из `src/requirements-build.txt`.

## Разработка

Исходники в папке `src/`:
- `index.html`, `styles.css`, `app.js` — интерфейс
- `launcher.py`, `bundle.py`, `build.bat` — сборка exe
- `Планер.xlsx` — исходный Excel-шаблон

Для проверки в браузере откройте `src/index.html`.
