# Планер v1.1

Недельный планер, матрица Эйзенхауэра и недельная статистика.

## Запуск

В корне лежит один файл **`Planer.exe`** — запускайте его двойным щелчком.

1. Скачайте или клонируйте репозиторий.
2. Запустите `Planer.exe`.

Папка `_internal` больше не нужна — всё упаковано в один exe.

Данные сохраняются локально на компьютере в **зашифрованном виде** (пароль задаётся при первом запуске).

## Защита

- **Лицензионный ключ** — обязателен при запуске `Planer.exe`
- **Шифрование данных** — AES-GCM + PBKDF2, пароль пользователя
- **Шифрованные бэкапы** — кнопки «Сохранить» / «Открыть»
- **Автобэкап** — периодическое сохранение в `%APPDATA%\Planer\backups\`
- **Обфускация JS** — код сжимается и упаковывается при сборке exe
- **Защита от копирования** — в desktop-режиме блокируются контекстное меню, Ctrl+U, F12 и DevTools (Ctrl+S и выделение текста в полях работают)
- **EULA** — см. файл `LICENSE`

### Активация

1. Запустите `Planer.exe`
2. Введите лицензионный ключ формата `PLAN-XXXX-XXXX-XXXX-XXXX`
3. Задайте пароль шифрования (не короче 6 символов)
4. Включите **«Запомнить на этом компьютере»** — следующие запуски будут быстрее

**Демо-ключ для теста:**

```
PLAN-75A3-A66F-F19B-3463
```

### Генерация ключей (для автора)

```bat
cd src
python generate_key.py customer-001
```

Перед выпуском измените секрет в `src/license.py` (`LICENSE_SECRET`).

## Возможности

### Недельный планер
- 7 дней недели (Пн–Вс) в одной строке, часы в шапке
- Подсветка **сегодняшнего** дня, клик по заголовку дня — прокрутка к колонке
- Переключение недель и кнопка «Сегодня»
- Компактный список задач, опция **скрывать выполненные**
- Перетаскивание задач между днями
- Прогресс, завершённые и невыполненные задачи
- Многострочные заметки (4 строки на день)
- **Копировать →** — перенос недели на следующую
- **Открыть** / **Сохранить** — импорт и экспорт `.planer` (перед восстановлением показывается отчёт о файле)
- **Печать** — печать текущей недели
- **Ctrl+Z** — отмена последних изменений
- Индикатор «Сохранено» / «Сохранение…»

### Матрица Эйзенхауэра
- 4 квадранта с поддержкой светлой/тёмной темы
- Кнопка **→** — добавить задачу в выбранный день недели
- Бейдж дня переноса и **↩** — вернуть задачу в матрицу
- Фильтр **«Скрыть перенесённые»**
- Синхронизация «выполнено» с недельным планером

### Недельная статистика
- Сводка: выполнено, не выполнено, прогресс
- Сравнение с прошлой неделей, лучший и сложный день
- Графики «Задачи по дням» и «Прогресс по дням»
- **Экспорт CSV**

### Настройки (⚙)
- Масштаб интерфейса (100% / 110% / 125%)
- Скрывать выполненные задачи
- Автобэкап и интервал (1 / 3 / 7 дней)
- Сворачивание в трей при закрытии окна
- Светлая / тёмная тема
- Цвет текста интерфейса и цвета колонок
- Смена пароля шифрования
- Автозапуск с Windows
- О программе (версия, путь к данным)

### Горячие клавиши
- `Ctrl+S` — сохранить бэкап
- `Ctrl+Z` — отменить последнее изменение
- `Ctrl+F` — поиск (с фильтрами: задачи / заметки / матрица)
- `←` / `→` — прошлая / следующая неделя
- `T` или `Home` — текущая неделя
- `Esc` — закрыть окно

## Структура проекта

```
planer/
  Planer.exe    — готовое приложение (один файл)
  src/          — исходники и сборка
    js/         — модули интерфейса
```

## Сборка exe

```bat
cd src
build.bat
```

Нужны Python 3, WebView2 Runtime и зависимости из `src/requirements-build.txt`. Перед сборкой закройте `Planer.exe`. Результат — один файл `Planer.exe` в корне проекта.

## Тесты

```bat
cd src
python -m unittest test_planer.py
```

## Разработка

Исходники в папке `src/`:
- `index.html`, `styles.css`, `js/` — интерфейс
- `launcher.py`, `bundle.py`, `build.bat` — сборка exe

Для проверки в браузере откройте `src/index.html`.
