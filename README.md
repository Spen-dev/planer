# Планер

Веб-приложение на основе файла `Планер.xlsx`.

## Возможности

### Недельный планер
- 7 дней недели (Пн–Вс) с цветовой схемой как в Excel
- Переключение недель (← →, выбор даты, кнопка «Сегодня»)
- До 15 задач на день с чекбоксами
- **Прогресс за день** — доля выполненных задач среди заполненных (как формула `G37/COUNTA(...)`)
- **Завершено** — число отмеченных задач (`COUNTIF(..., TRUE)`)
- **Невыполнено** — заполненные, но не отмеченные
- 4 заметки на день

### Матрица Эйзенхауэра
- Срочно и важно
- Срочно, но не важно
- Важно, но не срочно
- Не важно и не срочно

Данные сохраняются в `localStorage` браузера.

## Запуск (Windows)

Запустите **`Planer.exe`** — один файл, отдельное окно приложения, данные сохраняются локально.

### Сборка exe

```bat
build.bat
```

Создаёт один файл `Planer.exe` в корне проекта. Нужны Python 3 и [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/).

### Разработка в браузере

Откройте `index.html` в браузере.
